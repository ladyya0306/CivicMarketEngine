# Public Release Boundary

`CivicMarketEngine` is the noncommercial, source-visible public package.

It is generated by whitelist copying and explicit replacement. It must not be
created by copying the private workspace wholesale.

## Public Package Allows

- Offline mock smoke tests.
- Public documentation, licensing, attribution, and minimal examples.
- Non-sensitive helper code that does not expose private prompts or internal
  formal reproduction machinery.

## Public Package Excludes

- Private prompts and prompt tuning strategy.
- `AGENTS.md` and internal LLM/code boundary text.
- Formal reproduction harnesses and staged gate reports.
- Live LLM outputs and result artifacts.
- Secrets, local paths, caches, databases, spreadsheets, logs, and generated
  result folders.

## Positioning

This package is for noncommercial review, education, and mechanism discussion.
It is not a price prediction tool, not a production trading system, and not an
investment recommendation.
